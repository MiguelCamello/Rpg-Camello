Jogo de Rpg genérico escrito em python, utilizado SQLite para a arquitetura do banco de dados, para a interface visual, foi utilizado ASCII no terminal.



Requerimentos para rodar o projeto

Digite no terminal 
    pip install -r requirements.txt
para baixar as dependencias

Baixe a fonte localizada em assents e coloque a font no vscode, nas configurações

Para rodar o projeto, apenas abra o terminal estando dentro da pasta do projeto, e digite 
    python -m Rpg_Camello
e o projeto devera iniciar
